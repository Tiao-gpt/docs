# Threeebs :3 — Manifesto

Nem todo projeto nasce grande.

Mas todo projeto que importa começa com alguém tentando.

A Threeebs nasce desse tipo de começo.

A gente acredita que tecnologia não deveria ser uma porta fechada.

Não deveria exigir que você virasse outra pessoa para conseguir usá-la.

Criar um sistema não precisa ser um salto no escuro.

A gente não promete mágica.

Promete parceria.

Trabalho humano onde faz sentido.

Inteligência artificial onde faz sentido.

E uma base técnica que aguenta o tempo.

Enquanto um projeto está com a gente, a responsabilidade é compartilhada.

E quando precisa seguir outro caminho, isso também é possível.

Porque autonomia não é um bônus.

É parte do princípio.

No fim, tecnologia também é relação.

E, para a gente, crescer só faz sentido se for ao lado de quem confia na gente.

```text
Ideia
  ↓
Primeiro passo
  ↓
Sistema
  ↓
Pessoas
  ↓
Equipe
  ↓
Ecossistema
```

A Threeebs quer estar no começo dessa jornada.

E continuar ao lado enquanto fizer sentido.

Ajudando a construir o barco para essa viagem.
